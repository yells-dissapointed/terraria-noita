Noita wand compatibility mod with an in-game deck editor, XML spell adapters and refillable mixed-liquid flasks. v0.9.0 adds shared-volume fluid mixtures, density settling and imported binary reaction recipes. Native water/lava/honey interact with custom fluids locally. Use /noita probe to inspect mixtures and /noita reactions A B to explain a recipe. Requires your own extracted Noita data configured in mod settings. Use /noita kit for both wands and flasks. The debug wand supports fixed spells, movement/elemental modifiers, harmless previews and JSON reports. Original Noita sprites use 1.75x scaling; Terraria sprites retain their native size. Single-player only. This is a partial adaptation: native pixel physics, complete chemistry and secondary entity scripts remain incomplete. Use a test world for live terrain-changing spells and harmful liquids.
