Noita wand compatibility mod with an in-game deck editor, XML spell adapters, flowing custom materials and refillable mixed-liquid flasks. Requires your own extracted Noita data configured in mod settings. Left-click casts; right-click edits cards and wand stats. Use /noita kit for the wands and flasks. The debug wand supports fixed spells, movement/elemental modifiers, harmless previews and JSON reports. Original Noita sprites use 1.75x scaling; Terraria sprites retain their native size. Single-player only. This is a partial adaptation, not the native Noita engine; entity scripts, detailed chemistry and secondary spell effects remain incomplete. Use a test world for live spells that destroy terrain or produce harmful liquids.
